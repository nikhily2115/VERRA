## 🆘 **TROUBLESHOOTING**

### **Common Issues & Solutions**

#### **1. Build Fails on Vercel**
- **Check**: Node.js version (Vercel uses 18.x by default)
- **Fix**: Add `.nvmrc` file with `18` if needed

#### **2. Environment Variables Not Working**
- **Check**: Variables start with `REACT_APP_`
- **Fix**: Redeploy after adding variables

#### **3. 404 on Page Refresh**
- **Problem**: SPA routing
- **Solution**: Already fixed in `vercel.json`

#### **4. API Calls Fail**
- **Problem**: Backend not deployed yet
- **Solution**: Deploy backend and update `REACT_APP_API_URL`
